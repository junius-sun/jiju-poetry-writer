# AI 配置与使用

先按 [README](../README.md#本地启动) 启动 Node 服务，再打开它提供的地址。GitHub Pages 只有静态前端，不能提供本项目的 AI 接口。

## 在页面中配置

1. 进入自由集句，点击「添加素材 · AI 设置」，展开「配置 AI 模型」。
2. 填写 API 根地址和服务实际提供的模型名称。根地址通常以 `/v1` 结尾，后端会追加 `/chat/completions`。
3. 填写自己的密钥、保存，点击「测试连接」。测试会实际调用一次文字模型，可能消耗所用服务的额度。
4. 图片模型可单独填写，留空继承文字模型；文字连接成功不代表视觉输入也已验证。

仓库中的地址和模型名只是配置示例，不附带可用密钥。请不要把密钥写入 README、前端代码、截图或 Git 提交。

| 配置项 | 当前行为 |
| --- | --- |
| API 根地址 | 兼容 Chat Completions；远程接口需 HTTPS，本机接口可用 HTTP |
| 文字／图片模型 | 使用服务实际提供的名称，图片理解需要视觉能力 |
| 结构化输出 | 默认严格 JSON Schema；兼容性不足时可选 JSON Object |
| 输出长度参数 | 默认 `max_completion_tokens`；部分兼容服务需要 `max_tokens` |
| 等待时间 | 默认 120 秒，可配置 30–300 秒；浏览器额外留 30 秒接收处理结果 |
| 思考模式 | 可选自动、关闭、开启；自动模式会对适配的豆包 Seed 模型关闭深度思考 |
| 密钥修改 | 留空保留已存密钥；通过「移除密钥」清除 |

配置保存在 `.local/ai-config.json`，密钥为本机明文存储，保存后不会回传给页面。该目录已被 Git 忽略，也不会作为静态文件提供。

## 使用环境变量

将项目根目录的 `.env.example` 复制为 `.env.local`，填写后重启服务：

```dotenv
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=your-model-name
AI_API_KEY=your-own-key
AI_VISION_MODEL=
AI_VISION=true
AI_OUTPUT_MODE=schema
AI_TOKEN_FIELD=max_completion_tokens
AI_TIMEOUT_SECONDS=120
AI_THINKING_MODE=auto
```

环境变量优先于页面配置，对应输入会锁定。也支持以 `OPENAI_API_KEY` 提供密钥。`.env.local` 不应提交；需要分享配置时只分享不含密钥的 `.env.example`。

## 让 AI 帮助选句

先选择诗体与韵部。素材可不填，直接按当前设定推荐；有素材时可以写主题、导入文档或图片，保存后让 AI 理解并推荐。

AI 推荐、合律候选和手动检索共用字数、句位、韵部约束。服务端先提供最多 40 条候选，模型返回最多 5 个已有编号和理由，再由程序复核。推荐阶段只发送创作方向、已选句和候选，不重复发送原图及全文文档。

四句完成后可以请求诗意点评。点评讨论语义、意象、情绪和余韵，不替代格律检查。修改素材、诗句或方向后，过期请求会取消，不沿用不适用的推荐。

## 连接失败或超时

- **提示本机服务未连接**：确认启动窗口仍在运行，浏览器打开的是该服务地址，再点击「重新连接」。Windows 启动脚本端口为 4319，`npm start` 默认为 3000。
- **鉴权失败**：核对密钥、接口地址及该密钥可用的模型，不要反复提交错误密钥。
- **不支持的参数或输出格式**：根据服务的接口要求，调整结构化输出与 token 参数。
- **持续超时**：先测试较短请求，核对模型状态；可适度提高等待时间，支持时关闭深度思考。页面可取消当前任务，不必反复点击造成重复请求。
- **图片失败但文字正常**：确认实际选择的模型支持视觉，且服务接受图片输入。
- **额度或频率受限**：检查服务账户状态，按其提示等待或调整配置。

最多同时处理两个请求，成功结果在服务端内存中缓存 10 分钟，最多 40 份；失败不自动重试。测试覆盖本地模拟接口，不能保证每一种兼容服务的行为或文学评价质量。

## 部署边界

接口限制为本机访问，并对保存配置和模型请求执行同源检查。不要通过改监听地址直接将它作为公共 AI 服务使用。面向公众开放前，应补齐鉴权、额度限制与服务端密钥管理。
