# AI 配置与使用

[在线版](https://junius-sun.github.io/jiju-poetry-writer/) 默认从浏览器直接连接模型服务，不需要本地 Node 服务。每位访客使用自己的 API Key，本站不提供公共密钥。

## 三步连接

1. 进入自由集句，点击「添加素材 · AI 设置」，展开「连接 AI · 填写 Key」。
2. 选择模型服务，粘贴该服务的 API Key。
3. 点击「连接 AI」，页面会自动测试文字模型；成功后即可理解素材、推荐诗句与点评。

默认只显示服务与 Key 两个输入。OpenRouter 预设使用 `openrouter/free` 自动路由，OpenAI 预设使用 `gpt-4.1-mini`；地址、模型和输出参数已预填，可在高级设置修改。可用额度、价格、模型和调用频率由服务方决定，免费路由不保证随时可用或无限使用。连接测试会调用一次模型，可能消耗额度。

**Key 仅保留在当前页面内存中，不写入 localStorage、sessionStorage 或 URL，不上传本站；刷新或关闭页面后需重新填写。** 点击「移除 Key」可清除当前连接。切换服务后，需要填写新服务自己的 Key。请勿将密钥写入源码、截图或 Git 提交。

## 高级设置

通常无需修改。其他兼容服务请选择「自定义兼容服务」，再填写地址和模型。

| 配置项 | 行为 |
| --- | --- |
| API 根地址 | 兼容 Chat Completions，自动追加 `/chat/completions`；远程接口须 HTTPS，本机可用 HTTP |
| 文字／图片模型 | 使用服务实际提供的模型名；图片模型留空继承文字模型 |
| 允许图片输入 | 所选模型和服务都须支持视觉；文字连接成功不代表视觉已验证 |
| 结构化输出 | 严格 JSON Schema 或兼容 JSON；按服务支持情况选择 |
| 输出长度参数 | `max_completion_tokens` 或 `max_tokens`；预设已按服务填入 |
| 等待时间 | 默认 120 秒，可配置 30–300 秒 |
| 连接方式 | 默认浏览器直连；仅本机页面显示可选的本机代理 |

浏览器直连需要服务允许网页来源的跨域请求（CORS）。服务不允许跨域时，增加等待时间不能解决；本地运行可选择本机代理。Pages 本身不能运行 Node 代理。

## 让 AI 帮助选句

先选择诗体与韵部。素材可不填，直接按当前设定推荐；也可以写主题、导入文档或图片，让 AI 理解后推荐。只有主动调用 AI 时，相关素材才发往你选择的模型服务。

程序先筛出最多 40 条候选，模型返回最多 5 个已有编号及理由，程序再复核编号、字数、句位和韵部；不会采用模型编造的诗句或出处。推荐阶段只发送创作方向、已选句和候选，不重复发送原图及全文文档。

四句完成后可请求诗意点评，讨论语义、意象、情绪与余韵，不替代格律检查。修改素材、诗句或方向会取消过期请求。可随时取消等待，或继续手动选句。

## 可选：本机代理

先按 [README](../README.md#本地启动) 启动 Node 服务，在高级设置将连接方式改为「本机代理」。页面配置会保存到 `.local/ai-config.json`，Key 为本机明文，不回传浏览器；该目录已被 Git 忽略，也不作为静态文件提供。切回浏览器直连后需重新填写 Key，不会从代理取回密钥。

也可以将 `.env.example` 复制为 `.env.local`，填写后重启服务：

```dotenv
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4.1-mini
AI_API_KEY=your-own-key
AI_VISION_MODEL=
AI_VISION=true
AI_OUTPUT_MODE=schema
AI_TOKEN_FIELD=max_completion_tokens
AI_TIMEOUT_SECONDS=120
```

环境变量优先于页面配置，对应输入会锁定；也支持 `OPENAI_API_KEY`。不要提交 `.env.local`。本机代理仅供回环地址使用；公共代理需要独立的鉴权、额度和密钥管理。

## 连接失败或超时

- **无法连接／跨域错误**：检查网络和接口的 CORS 支持；本地页面可尝试本机代理。
- **鉴权失败**：核对所选服务、Key、模型权限及账户状态。
- **不支持的输出格式或参数**：在高级设置调整结构化输出和输出长度参数。
- **持续超时**：检查服务状态、尝试响应更快的模型，或适当增加等待时间。请求失败不会自动重试。
- **图片失败但文字正常**：确认视觉开关、图片模型和接口均支持图片输入。
- **额度或频率受限**：按服务方提示等待或调整账户配置，切勿把免费路由理解为无限额度。
- **本机代理未连接**：保持启动窗口运行，并打开服务提供的地址；Windows 脚本端口为 4319，`npm start` 默认 3000。

每个调用实例最多同时处理两个请求，成功结果在内存缓存 10 分钟，最多 40 份；修改连接配置会清除浏览器实例缓存。回归测试使用模拟接口，不代表真实 Key、所有兼容服务或文学评价质量已验证。
