# 诗境集句

**借古人的诗句，写此刻的心意。**

从真实古诗原句中选句、押韵、成篇，再留作一张水墨诗笺。程序检查格律与出处，AI 辅助理解心意、比较候选；最后如何取舍，由你决定。

[GitHub Pages](https://junius-sun.github.io/jiju-poetry-writer/) · [本地启动](#本地启动) · [AI 配置](docs/AI_CONFIGURATION.md) · [语料说明](#语料与出处)

![诗境集句首页](docs/images/home.png)

## 可以做什么

| 功能 | 内容 |
| --- | --- |
| 自由集句 | 选择五言或七言绝句，按步骤完成素材、选句与诗牌制作 |
| 自选押韵 | 选择 30 个平水韵平声韵部，或随首个入韵句自动定韵 |
| 手动找句 | 按诗句、作者、篇名或意象检索，查看主出处与本库收录句 |
| AI 共酌 | 理解文字、文件和图片，推荐真实候选诗句，点评成诗的连贯与意境 |
| 飞花闯关 | 在诗体、韵部、意象或作者限制下完成集句；含集杜模式 |
| 水墨诗牌 | 六款《文美斋诗笺谱》花笺、四款本地书法字体、横竖排与 3× PNG 导出 |
| 诗词入门 | 了解集句、五言七言、绝句律诗与平水韵，再通过外部资料深入阅读 |

界面沿用暖纸、墨色与朱砂配色。首页与创作工作区分开，语料和文档解析器按需加载；动效可关闭，也遵循系统的减少动态效果设置。

## 本地启动

需要 **Node.js 22.13 或更高版本**，自带 npm。安装依赖时需要网络。

```bash
git clone https://github.com/junius-sun/jiju-poetry-writer.git
cd jiju-poetry-writer
npm ci
npm start
```

打开 **[http://localhost:3000](http://localhost:3000)**。使用期间保持服务运行，按 `Ctrl+C` 停止。

Windows 也可以在安装依赖后双击 **`启动诗境.cmd`**，该入口使用 **[http://localhost:4319](http://localhost:4319)**，与 `npm start` 的默认端口不同。

本地找句、格律校验、闯关和诗牌制作不需要 API 密钥。GitHub Pages 提供静态前端；**AI 功能需要本地 Node 服务**，不能直接在 Pages 上调用本项目的后端。

## 从心意到诗笺

1. **定诗体与韵部**：选择五言／七言和想押的韵，也可以自动定韵。
2. **找句成诗**：直接手动检索或浏览合律候选；也可添加素材，让 AI 理解方向并逐句推荐。
3. **核对出处与格律**：每句显示一个主出处，可展开本库收录内容；四句成篇后再检查整体。
4. **留作一笺**：填写标题，选择花笺、书法字体、纸色与排版，导出图片。

素材支持文字、TXT、Markdown、DOCX、PDF，以及 JPG、PNG、WebP 图片。每次最多 6 个附件，单个不超过 10 MB、合计不超过 30 MB；PDF 最多 50 页。扫描 PDF 需要改用图片输入。

导入和预览在本地完成。**只有显式调用 AI 时，相关素材才发送至配置的模型服务。** 未持久保存的诗稿与素材在刷新后需要重新输入；页面内切换步骤不会清空它们。

## AI 接入

在创作页点击 **「添加素材 · AI 设置」→「配置 AI 模型」**，填写兼容 Chat Completions 的 API 根地址、模型名称和密钥，保存后测试连接。没有 API 时，可以先填写配置，继续使用手动创作。

- 文字与视觉模型可分别配置；图片理解需要所选服务支持视觉输入。
- 程序先筛出合律候选，AI 在已有候选编号中比较诗意，服务端再复核编号；不采用模型自行编造的诗句或出处。
- AI 点评与格律判定分开，文学评价不会改变闯关规则。
- 等待时可取消；超时或服务失败后，仍可继续手动选句。

密钥保存在被 Git 忽略的 `.local/ai-config.json`，也可使用 `.env.local`。**仓库不附带 API 密钥或免费额度**，模型是否收费由服务提供方决定。

完整步骤、环境变量与超时排查见 **[AI 配置说明](docs/AI_CONFIGURATION.md)**。

## 语料与出处

当前运行库收录 **561,809 句**：五言 329,074 句、七言 232,735 句。其中唐代 367,770 句、宋代 109,090 句；这不是全唐诗或全宋诗的完整收录。

原文核对来源包括固定版本的 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry/tree/b8594f81a89752241442f2ce267d6f66f96704ee) 与 [haitangshishe](https://github.com/muskjobstao/haitangshishe/tree/90b53bfab67275e8b2e8e94807515b77fc17f2ba)。现有语料经过简繁转换、去重、出处匹配及平仄／韵部标注，并不是直接使用某一个上游数据库的全部内容。

采用 **「一句，一个已匹配主出处」** 的运行策略：待核、署名冲突和多版本主出处未定的条目移出运行库；附加引用只保留在核对档案中。主出处是本项目的收录依据，不表示这句话在文学史上只出现于一篇作品。

| 运行数据 | 大小 |
| --- | ---: |
| 默认 gzip 下载 | 16.44 MB |
| 紧凑 JSON 回退 | 47.82 MB |
| 原六个 JavaScript 分片 | 156.00 MB |

首页不加载整库，进入创作工作区后才下载语料；支持浏览器原生解压，失败时回退 JSON。压缩是无损编码，数量、大小和 SHA-256 记录在 [corpus.meta.json](src/data/corpus.meta.json)。

核对策略、原始备份与排除原因见 [单一出处报告](reports/corpus-single-source.md)。这些离线档案不参与应用或 AI 的运行加载。

## 格律规则与边界

- 支持五言、七言平韵绝句的四种基本格式，检查字数、平仄、粘对、孤平和三平尾；允许常见的孤平本句自救，三仄尾不一概判错。
- 第二、四句须押同一明确的平声韵部；首句入韵时同韵。当前严格模式不处理首句借邻韵及其他特殊拗救。
- 项目规则要求四句出自不同原诗，不得重复选句；集杜模式也使用同一格律校验。
- 闯关先通过基础校验，再检查关卡条件。规则检查通过不等于诗意优秀。
- 古音标注仍有字典覆盖与多读字的限制，不能替代语境辨音；运行库仍可能含词、曲或文体未分类的五／七字片段。
- 程序匹配与开源合集不等同于权威校勘，重要引用请继续核对原典。

## 技术与目录

原生 HTML、CSS、JavaScript ES Modules；Node.js 提供静态文件与本机 AI 接口，不依赖数据库服务，也不需要前端生产构建。

```text
├── index.html              # 介绍首页
├── server.js               # 本地服务入口
├── server/ai/              # 模型配置、调用与候选复核
├── src/
│   ├── app.js              # 集句、检索、闯关等交互
│   ├── bootstrap.js        # 工作区异步启动
│   ├── ai/                 # AI 设置、推荐与点评
│   ├── input/              # 文字、文档与图片素材
│   ├── ui/                 # 工作区、首页、诗牌与样式
│   ├── engine/             # 格律与韵部规则
│   └── data/               # 压缩语料与编解码、出处工具
├── assets/                 # 字体、古笺与品牌字标
├── vendor/                 # 按需加载的前端依赖
├── scripts/                # 语料处理和资源构建
├── tests/                  # 回归测试
├── reports/corpus-*        # 数据核对档案
└── docs/                   # 使用说明
```

## 验证与数据维护

```bash
npm test                  # 格律、数据、出处、素材、AI 模拟接口、诗牌测试
npm run test:smoke        # 全量语料与真实候选的冒烟验证
npm run build:importers   # 重建文档解析组件
npm run build:data        # 无损编码并重新压缩当前语料
npm run fetch:sources     # 下载固定版本原文快照，需要网络
npm run data:quality      # 核对出处、清理文体和标注，重新压缩
npm run data:single-source # 重做单一主出处筛选
```

日常运行不需要执行数据维护命令。维护脚本会改写语料与报告，操作前请保留备份；`scripts/_tmp_sources/` 为可重新获取的本地缓存，不随仓库上传。字体重分包另需 Python 与 fontTools，见 [字体说明](assets/fonts/SOURCES.md)。
