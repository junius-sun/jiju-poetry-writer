# 诗境集句 (ShiJing Jiju)

前人句拼接 · 今人意再造 · 严合平水韵

在线体验：https://junius-sun.github.io/jiju-poetry-writer/
GitHub 仓库：https://github.com/junius-sun/jiju-poetry-writer

---

## 项目背景

“集句诗”是古典诗词中一种独特的创作形式，即不写一句新词，全凭挑选前人名篇中的句子拼接组装成一首意境全新的新绝句（如南宋文天祥集杜甫诗）。

然而，传统集句诗创作门槛极高：
1. 记忆储备要求高：脑海中必须具备海量的诗词储备。
2. 格律限制极严：既要遵守《平水韵》押韵，又必须符合近体诗严苛的平仄对粘与一三五不论规则。

本项目由一名文科生通过 Vibe Coding（与 AI 结对编程）开发完成。旨在利用算法自动化处理最繁琐的格律校验与文献检索，让创作者能够专注于意境选择与组合审美，降低集句诗创作门槛。

---

## 核心功能

1. 实时格律分析与平水韵校验
   - 自动识别古音入声字与平仄矩阵。
   - 校验偶数句平水韵押韵、粘律、避孤平及避失粘。

2. 智能续句推选
   - 选定首句后，自动筛选 100% 严合格律的候选续句。
   - 支持换一批翻页，探索不同意境。

3. 名句检索与全诗折叠
   - 支持按意象（如明月、思乡、边塞）或按诗人/诗名检索。
   - 搜索结果按原诗分组并支持折叠展开全诗。

4. 飞花闯关与集杜模式
   - 提供限定韵部与意象的闯关关卡。
   - 支持“集杜模式”，锁定同一诗人的不同名篇进行组装。

5. 水墨诗牌定制与图片导出
   - 支持 4 种宣纸底色（古朴宣纸、清雅竹青、玄青墨玉、朱砂紫檀）。
   - 支持 4 种框纹风格（雅致素宣、飞花洒金、锦缎装帧、诗笺朱栏）。
   - 支持 5 种名家字体（马善政行书、Long Cang 随性、思源宋体、霞鹜文楷、钉钉进步体）。
   - 支持传统竖排与现代横排自由切换。
   - 提供 3x 高清 PNG 图片导出功能，方便保存与分享。

## 快速开始

运行环境要求：Node.js >= 18

1. 克隆仓库
```bash
git clone https://github.com/junius-sun/jiju-poetry-writer.git
cd jiju-poetry-writer
```

2. 安装与运行
```bash
npm install
npm start
```

3. 打开浏览器访问 http://localhost:3000

---

## 技术架构

- 架构：纯前端 + 极简 Node.js 静态文件托管，无数据库与外部 API 依赖。
- 引擎：纯函数格律校验引擎 (src/engine/metrical.js)。
- 渲染：基于 html2canvas 实现诗牌 Canvas 3x 高清图片渲染导出。
