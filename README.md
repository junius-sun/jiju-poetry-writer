# 诗境集句 (ShiJing Jiju)

前人句拼接 · 今人意再造 · 严合平水韵

在线体验：https://junius-sun.github.io/jiju-poetry-writer/
GitHub 仓库：https://github.com/junius-sun/jiju-poetry-writer

---

## 项目定位

“诗境集句”是一个基于历代古诗词数据库与近体诗格律校验引擎的**互动式古典诗词集句创作与辅助工具**。

“集句诗”是古典诗词中一种独特的创作形式，即不写一句新词，全凭挑选前人名篇中的句子拼接组装成一首意境全新的新绝句（如南宋文天祥集杜甫诗）。

传统集句诗创作对知识储备要求极高，且须严格遵循《平水韵》与近体诗平仄格律。本项目旨在通过算法自动化处理最繁琐的格律校验与文献检索，让创作者能够专注于诗意组合与审美决策，降低古诗集句创作的门槛。

## 语料与数据分析

本项目构建了包含约 69.7 万条历代五/七言诗句的精细化预处理语料库：

| 维度 | 统计说明 |
|---|---|
| 诗句条目总数 | 697,920 句 |
| 去重诗篇数 | 74,355 首（按作者+题去重） |
| 独立作者数 | 5,043 位 |
| 朝代分布 | 唐诗 66% / 宋诗 17% / 元诗 13% / 汉魏等 4% |
| 句长分布 | 五言 60% / 七言 40% |
| 格律标注 | 全量标注《平水韵》106 韵部、平仄编码与意象标签 |

数据来源包含全唐诗（chinese-poetry 开源库）及宋诗/汉魏古体，经 opencc 繁转简、平仄/韵部/意象全量标注、内容级去重与预处理分片。构建脚本见 `scripts/`。

## 核心功能

1. 实时格律分析与平水韵校验
   - 自动识别古音入声字与平仄矩阵。
   - 校验偶数句平水韵押韵、粘律、避孤平及避失粘。

2. 智能续句推选
   - 选定首句后，自动筛选 100% 严合格律的候选续句。
   - 支持“换一批”翻页，探索不同意境。

3. 名句检索与全诗折叠展示
   - 支持按意象（如明月、思乡、边塞）或按诗人/诗名检索。
   - 搜索结果按原诗分组并支持折叠展开全诗。

4. 飞花闯关与集杜模式
   - 提供限定韵部与意象的闯关关卡。
   - 支持“集杜模式”，锁定同一诗人的不同名篇进行组装。

5. 水墨诗牌定制与 3x 高清图片导出
   - 支持 4 种宣纸底色（古朴宣纸、清雅竹青、玄青墨玉、朱砂紫檀）。
   - 支持 4 种框纹风格（雅致素宣、飞花洒金、锦缎装帧、诗笺朱栏）。
   - 支持 5 种名家字体（马善政行书、Long Cang 随性、思源宋体、霞鹜文楷、钉钉进步体）。
   - 支持传统竖排与现代横排自由切换。
   - 提供 3x 高清 PNG 图片导出功能，方便保存与分享。

## 快速开始

运行环境要求：Node.js >= 18

1. 克隆仓库
```bash
git clone https://github.com/junius-sun/jiju-poetry-writer.git
cd jiju-poetry-writer
```

2. 安装与运行
```bash
npm install
npm start
```

3. 打开浏览器访问 http://localhost:3000

## 技术架构

```
浏览器 ──▶ server.js（Node.js 静态托管, :3000）
              │
              ▼
        src/app.js（前端主逻辑：诗架/推选/搜索/闯关/诗牌）
              │
              ▼
        src/engine/metrical.js（MetricalEngine 纯函数格律引擎）
              │
              ▼
        src/data/（697,920 句语料分片 + Word_Tune 字典 + 平水韵表）
```

- 纯前端 + 极简 Node.js 静态服务，无后端 API 与数据库依赖。
- 数据在构建期完成预处理标注，运行时只读、零计算成本。
- 基于 html2canvas 实现诗牌 Canvas 3x 高清图片渲染导出。

## 已知说明

- 语料含少量元曲/赋/散文切句（按标点切成 5/7 字块），集句时可能出现个别内容稍显违和的候选句，格律上无碍。
- 平水韵字典有少量多音字标注偏差，不影响主流押韵判定。
