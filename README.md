# 诗境集句 · ShiJing Jiju

> 前人句拼接 · 今人意再造 · 严合平水韵

一个交互式**古典集句诗创作工具**：从约 **69.7 万条**历代五/七言诗句（全唐诗、宋诗、汉魏古体、古诗文网全量）中，按《平水韵》韵部与近体诗格律规则，帮你拼出押韵合规、平仄严整、意象相合的原创绝句。

零基础也能玩——格律、押韵、避重字全部由规则引擎自动把关，你只管挑喜欢的句子。

## ✨ 功能特性

- **AI 智能推选**：基于格律规则引擎（平水韵 106 部 + 平仄对粘），100% 押韵保证的续句推荐，支持「换一批」随机翻牌（同分洗牌、单字零重复、新作者奖励）
- **双搜索**：按意象（明月、思乡、边塞…）或按诗人/诗名检索，结果按诗分组、可展开全诗
- **实时格律矩阵**：逐句平仄/对粘/押韵可视化 + 成诗评分评级（甲等·浑然天成 / 乙等·格律严整 / 丙等·初步成诗）
- **集杜模式**（同源铁律）：锁定单家（如杜甫）集句，句句出自不同原诗
- **飞花闯关**：按韵部 / 意象 / 名家条件挑战关卡
- **水墨诗牌导出**：宣纸 / 竹青 / 墨玉 / 朱砂四色主题，竖排或横排，一键导出成图

## 🚀 快速开始（本地运行）

需要 **Node.js ≥ 18**。

```bash
git clone <your-repo-url>
cd <repo-dir>
npm install
npm start
```

然后浏览器打开 **http://localhost:3000** 即可使用。

> 提示：首次加载需解析约 150MB 语料（6 个分片），本地约 2~3 秒；集句检索仍为亚秒级。

## 🏗️ 技术架构

```
浏览器 ──▶ server.js（Node 静态托管, :3000）
              │
              ▼
        src/app.js（前端交互：诗架/推选/搜索/闯关/诗牌）
              │
              ▼
        src/engine/metrical.js（MetricalEngine 纯函数规则引擎）
              │
              ▼
        src/data/（697,920 句语料, 6 分片 + Word_Tune 平仄字典 + 平水韵 105 部）
```

- 纯前端 + 极简 Node 静态服务，**无后端 API、无数据库、无外部依赖**（仅 opencc-js 用于数据构建期的繁简转换）
- 数据在构建期完成预处理标注（平仄编码、韵部、意象标签），运行时引擎只读、零计算成本

## 📊 语料数据

| 维度 | 数量 |
|---|---|
| 诗句条目 | 697,920 句 |
| 去重诗（作者+题） | 74,355 首 |
| 独立作者 | 5,043 位 |
| 朝代 | 唐 66% / 宋 17% / 元 13% / 汉魏等 4% |
| 句长 | 五言 60% / 七言 40% |

数据来源：全唐诗（chinese-poetry 开源库）、宋诗/汉魏古体（古诗文网 dump），经 opencc 繁转简、平仄/韵部/意象全量标注、内容级去重。构建脚本见 `scripts/`（`build_full_corpus.js` / `merge_gushiwen.js` / `normalize_full.js` 等）。

## ⚠️ 已知说明

- 语料含少量元曲/赋/散文切句（按标点切成 5/7 字块），集句时可能出现个别"内容违和"的候选句，格律上无碍。
- 平水韵字典有少量缺字/多音字标注偏差（如「啼」「佳」），不影响主流押韵判定。
